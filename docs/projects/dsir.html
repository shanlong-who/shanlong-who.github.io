DSIR

Access WHO and UN data, work with country metadata, and create consistent charts and tables.

01

The question

How can routine health-data work become easier to repeat, from retrieving observations to producing clear outputs?

What the package offers

DSIR brings together data clients for WHO GHO, WHO GHE, and UN SDG sources, country metadata, and reusable plotting and table styles. Its documentation describes the source-specific functions and their arguments.

Who it is for

Analysts who work in R with health indicators and need consistent data-access and reporting workflows.

A starting point

Install the package from CRAN with install.packages("DSIR"), then open its help index:

library(DSIR)
    help(package = "DSIR")

Using the results

Check the indicator definition, units, population, time coverage, and source before comparing observations. Use the project documentation to distinguish the CRAN release from GitHub development features.
