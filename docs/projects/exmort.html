Mortality analysis

exmort

Explore all-cause and excess mortality with baseline models, clear plots, and downloadable reports.

Read the guide ↗View source ↗
02

The question

How many deaths were observed compared with a statistical baseline, and how does the answer depend on the model and the periods selected?

What the app offers

Supply weekly or monthly death counts and an event calendar. The application fits baseline models using periods outside the supplied events and reports expected deaths, excess deaths, P-scores, uncertainty, plots, and downloadable reports.

Who it is for

Analysts exploring mortality time series who need to review model choices and explain the resulting estimates.

A starting point

Install from CRAN with install.packages("exmort"), then launch the app from R:

library(exmort)
    run_app()

The project website hosts documentation. The analysis runs in the Shiny application on your machine.

Interpreting the analysis

The event calendar and baseline period affect the result. Periods outside the supplied events can include observations after an event. Review the data range and the model guidance before interpreting an estimate. The GitHub documentation separately describes development features such as cause-specific analyses.
