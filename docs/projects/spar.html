SPAR Insights

Explore public SPAR self-assessment data across years, regions, and countries.

Open dashboard ↗View source ↗
04SPAR2021 — 2025

The question

How can publicly available SPAR self-assessment data be explored across years, regions, and countries in one place?

What the dashboard offers

Filter the 2021–2025 snapshot by year, WHO region, and State Party. Explore maps, score distributions, country profiles, annual comparisons, searchable comments, and downloadable tables.

Who it is for

People exploring public SPAR reporting who need an accessible way to browse patterns and return to the underlying sources.

A starting point

Open the dashboard in a modern browser. No R installation is needed to view it. The repository also provides a self-contained HTML file for offline use.

Reading the data

SPAR is a self-assessment. Country coverage can change between years, missing values differ from zero scores, and later official releases may differ from this snapshot. Read the dashboard’s data notes before making comparisons.

My contribution

I built and maintain this independent exploration tool. The repository includes the build and validation source. It is not an official WHO publication.
