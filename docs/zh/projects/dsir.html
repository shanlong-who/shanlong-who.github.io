R 数据工具包

DSIR

获取 WHO 与 UN 数据，使用国家元数据，并生成风格一致的图表与表格。

阅读指南（英文） ↗查看源代码 ↗
01

从什么问题出发

如何让日常健康数据工作更容易重复完成，从获取观测数据，到形成清楚的分析输出？

工具提供什么

DSIR 汇集了 WHO GHO、WHO GHE 与 UN SDG 数据客户端、国家元数据，以及可重复使用的图表和表格样式。项目文档说明各数据源对应的函数与参数。

适合谁使用

在 R 中处理健康指标，希望统一数据获取和报告工作流程的分析人员。

从这里开始

使用 install.packages("DSIR") 从 CRAN 安装，然后打开帮助索引：

library(DSIR)
    help(package = "DSIR")

理解使用结果

比较数据前，先检查指标定义、单位、人群、时间覆盖和来源。使用项目文档确认 CRAN 正式版与 GitHub 开发版之间的功能区别。
