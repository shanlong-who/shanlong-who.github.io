死亡率分析

exmort

利用基线模型分析全因死亡与超额死亡，查看图表并导出报告。

阅读指南（英文） ↗查看源代码 ↗
02

从什么问题出发

实际观察到的死亡人数与统计基线相比有多少差异？模型和时间段的选择又会怎样影响结果？

工具提供什么

输入每周或每月死亡人数与事件时间表，应用使用指定事件之外的时期拟合基线模型，并输出预期死亡、超额死亡、P-score、不确定性、图表和可下载报告。

适合谁使用

需要探索死亡时间序列、比较模型选择，并解释估计结果的分析人员。

从这里开始

使用 install.packages("exmort") 从 CRAN 安装，然后在 R 中启动：

library(exmort)
    run_app()

项目网页提供文档；实际分析在本机的 Shiny 应用中运行。

解释分析结果

事件时间表与基线时期都会影响结果。指定事件之外的时期可能包括事件发生后的观测值，解释估计结果前应检查数据范围与模型说明。死因别分析等开发功能在 GitHub 文档中另有说明。
